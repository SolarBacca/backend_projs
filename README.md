## Тема
Афиша мероприятий (Events). Данные хранятся в памяти программы.

## Поля сущности Event
- `id` (int) — серверный идентификатор
- `title` (str) — название мероприятия (обязательное)
- `date` (datetime) — дата и время проведения
- `location` (str) — место проведения (обязательное)
- `capacity` (int) — лимит участников

## Запуск
Предварительно требуется установка uv
https://docs.astral.sh/uv/getting-started/installation/


```bash
uv sync
uv run fastapi dev

```
## Эндпоинты

### Публичные (без авторизации)

| Метод | Путь                            | Описание                                                        | Коды ответа     |
|-------|---------------------------------|-----------------------------------------------------------------|-----------------|
| GET   | `/health`                       | Проверка здоровья сервиса                                       | 200             |
| POST  | `/auth/register`                | Регистрация пользователя (`username`, `password`; `role` задать нельзя) | 201, 400, 409   |
| GET   | `/auth/login`                   | Проверка креденшелов через Basic Auth                           | 200, 401, 429   |
| POST  | `/auth/login`                   | Выпуск JWT: `{"access_token": "...", "token_type": "bearer"}`   | 200, 400, 401, 429 |
| GET   | `/api/events`                   | Список мероприятий; фильтры: `?q=` (поиск по title), `?skip=`, `?limit=` | 200       |
| GET   | `/api/events/{id}`              | Мероприятие по ID                                               | 200, 404        |
| GET   | `/api/events/{id}/registrations`| Список регистраций на мероприятие                               | 200, 404        |

### Защищённые (нужен заголовок `Authorization: Basic ...` или `Authorization: Bearer <JWT>`)

| Метод  | Путь                             | Описание                                                          | Коды ответа            |
|--------|----------------------------------|-------------------------------------------------------------------|------------------------|
| GET    | `/auth/me`                       | Текущий пользователь (`id`, `username`); без пароля и хэша        | 200, 401               |
| POST   | `/api/events`                    | Создать мероприятие; `owner_id` проставляет сервер                | 201, 400, 401          |
| PUT    | `/api/events/{id}`               | Полная замена события (все поля обязательны)                      | 200, 400, 401, 403, 404 |
| PATCH  | `/api/events/{id}`               | Частичное обновление (только присланные поля)                     | 200, 400, 401, 403, 404 |
| DELETE | `/api/events/{id}`               | Удалить мероприятие (вместе с регистрациями, cascade)             | 204, 401, 403, 404     |
| POST   | `/api/events/{id}/registrations` | Регистрация участника; лимит `capacity` и уникальный email        | 201, 400, 401, 404, 409 |

### Значения кодов ошибок

| Код | Когда возвращается                                                              |
|-----|----------------------------------------------------------------------------------|
| 400 | Невалидное тело запроса (пустой `title`, `capacity < 1`, пустой PATCH)          |
| 401 | Нет заголовка авторизации / неверный логин или пароль / подделанный или просроченный JWT |
| 403 | Запись принадлежит другому пользователю (не владелец и не админ)                 |
| 404 | Ресурс с таким ID не существует                                                  |
| 409 | Дубликат логина при регистрации; дубликат email на мероприятии; лимит участников исчерпан |
| 429 | 5 неудачных попыток входа за минуту (лимит снимается успешным входом или через 60 с) |

## ER-диаграмма

Связь между таблицами **1:N** (одно мероприятие может иметь много регистраций).

```mermaid
erDiagram
    USER ||--o{ EVENT : "owns"
    EVENT ||--o{ REGISTRATION : "has registrations"
    USER {
        int id PK
        string username UK
        string password_hash
        string role
    }
    EVENT {
        int id PK
        string title
        datetime date
        string location
        int capacity
        int owner_id FK
    }
    REGISTRATION {
        int id PK
        string name
        string email
        int event_id FK
    }
